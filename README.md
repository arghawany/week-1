# Programming Assignment 1.1: Catch them all

In this assignment you'll install some software and set up your programming environment. Furthermore, you'll make a start with git!

You can preview the instructions of this assignment on https://mude.citg.tudelft.nl/workbook-2026/assignments/PA1.1/README.html. After the deadline, this link will include solutions. The preview without solutions will remain available here: https://mude.citg.tudelft.nl/workbook-2026/no_solutions/assignments/PA1.1/README.html. All files of an assignment can be downloaded as [`.zip`-file](https://mude.citg.tudelft.nl/workbook-2026/_custom_downloads/assignments/PA_1_1/all_files_PA_1_1.zip) to your computer.

To activate autograding and allow assistance by instructors, follow instructions as part of [the exercise 'Setup local file system and clone this assignment'](./09_setup_file_system.md).

Before you can start this assignment, read the theory pages in the book:

- [Getting Started!](https://mude.citg.tudelft.nl/book/2026/programming/week_1_1.html)
- [Version control with Git](https://mude.citg.tudelft.nl/book/2026/git/overview.html)

In this assignment you’ll make exercises on the following topics:

- Installing software and setting up your programming environment
- Git and GitHub

The autograder checks the following aspects of your work for each push to GitHub:

1. Commited multiple files together in a single commit as part of [exercise "Make commit locally"](./10_commit_local.md).
2. Replace the placeholder text in [exercise "Make commit online"](./12_commit_online.md) with your own content.

This assignment is due on 10:45, Wednesday, September 2, 2026.
